# MANTIF — Human × Artificial Intelligence
### Interactive Portfolio & Learning Hub Showcase

An interactive, cinematic portfolio for **MANTIF** — an MSME-registered EdTech startup in Tamil Nadu, India, bridging empathetic human pedagogy with intelligent AI tutoring systems.

---

## 🌟 Key Features

- **Theatrical Intro Sequence**: Human & AI character walking entrance and handshake convergence with dynamic subtitle and depth letter reveals.
- **What MANTIF Builds**: Interactive service panels for Tutoring Hub (Classes 6–10), Startup Ideation Guidance, and Freelancing Services, linking directly to `mantif.com`.
- **The People Behind MANTIF**: Arched luxury editorial showcase for founder Karunya S and 3D flip cards for the engineering team.
- **The Journey Stage (Puppet Theatre)**: Suspended kinetic pendulum letter stage tracing milestones from physical classrooms in 2024 to digital scale.
- **Why We Build (Philosophy)**: Spotlight manifesto experience with interactive sentence illumination.
- **Card-Free Architectural Contact Section**: Open 3-column editorial grid with verified helplines (`+91 98427 43538`, `+91 80564 53211`, `+91 63811 80488`), direct email (`info@mantif.com`), platform link (`mantif.com`), and social channels.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Keyframe Physics & Conic Light Beams
- **Motion & Audio**: Lenis Smooth Scrolling, Web Audio API Sound Synthesizer
- **Icons**: Lucide React

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
